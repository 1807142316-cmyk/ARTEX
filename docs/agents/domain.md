# 领域文档

本仓库采用 single-context 布局：根目录 `GLOSSARY.md` 和 `docs/adr/`。

## 探索前读取

- 读取根目录 `GLOSSARY.md`。
- 若存在 `GLOSSARY-MAP.md`，按其指向读取与当前主题相关的 context 词汇表。
- 读取 `docs/adr/` 中与当前工作相关的 ADR；若以后出现 context 级 ADR，也读取相关部分。

文件不存在时静默继续，不因配置本身创建空词汇表或 ADR。术语和决策实际得到解决时，再通过领域建模工作维护相应文档。

## 输出约定

Issue、spec、设计说明和测试名称使用词汇表定义的领域术语。新概念先核对现有词汇；确有缺口时记录待补术语，而非随意给同一概念改名。

发现方案与现有 ADR 冲突时，明确指出相关 ADR 和冲突原因，作为待解决决策记录；保留既有决策的来源与状态。
