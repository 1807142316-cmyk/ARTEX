## 当前范围覆盖规则（以本节为准）

用户最新指示：“自定义Agent你不用管了”。该指示优先于以下历史角色表和访谈推荐。项目使用时默认按用户配置的目标与工具运行，后续不在每项功能中重复说明这一前提。

- 本期不新增、改造或配置自定义 Agent；不交付其提示词、资源绑定、专用自动触发或角色之间的编排。
- 排除 retester、verifier、exploit、cloud、evasion、payout_analyst、hdb_curator 的新增/改造工作。已有自定义 Agent 管理、触发及报告/复测能力保持现状，不删除既有记录或改写用户配置。
- 原生知识库、CVE、技能管理、代理池、内网关系与会话适配、仪表盘和导航等平台模块仍在范围内；不能将自定义 Agent 作为这些模块的必需依赖。
- 最新内容要求：CVE语料、扫描模板、技能以及武器库中的实际内容一并交付；不能仅做管理界面和导入接口。来源调研、补充编写与验证由代理承担，原D25将缺少内容全部列作后补的建议已被用户否定。
- 内置 Agent 仍在范围内：目标拆解、规划、主、执行、Auto、渗透测试，以及 worker_intranet 上下文变体。运行时保留 goals/mainagent 等 key，名称/职责对齐；不强行迁移已有数据引用。
- “主角色清单必须恰好14个”“补齐全部自定义角色资源数”不再作为验收要求；角色列表按真实已配置内容展示，沿用截图的卡片结构。
- 自动独立验证、Agent 自动入库等依赖被排除角色的环节不能宣称已交付。已确认替代流程为：平台收集候选来源，人工编辑/导入/审核发布，验证状态关联真实证据，内置角色使用 kb_search/kb_get。
